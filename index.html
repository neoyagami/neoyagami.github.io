OpenGC570D

Giving a capture card a life on Linux.

An unofficial, experimental Linux kernel driver for the AVerMedia Live Gamer DUO GC570D. It exposes both HDMI inputs through V4L2 and ALSA, initializes HDMI IN 1 passthrough, and supports the enclosure's RGB lighting.

This is a more involved hardware project: installation requires building and loading a kernel module for the exact supported card. It was validated on Bazzite 44; testing on other distributions and hardware setups is welcome.

  • PCI ID 1461:0054 · subsystem 1461:5700
  • SDR capture up to 1920 × 1080 at 60 fps
  • Tested HDR-to-SDR conversion and downscaling
  • Rebuild required after each kernel update

Secure Boot requires a locally signed and enrolled module, or must be disabled. HDCP-protected content is unsupported. This project is not endorsed by AVerMedia.
